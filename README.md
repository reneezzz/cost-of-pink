# Cost of Pink

An interactive board game exploring gender-related economic inequalities, designed for two players or teams sharing one screen.

**[Play the game](https://reneezzz.github.io/cost-of-pink/)**

## 试玩

两个人共用一台电脑，轮流操作。当前版本提供中文操作与情境说明，保留原始英文棋盘与卡面。无需安装或登录；游戏进度仅保存在当前浏览器中。不同设备打开网址会开始各自的对局，不会联机同步。

每人初始 $100，随机分配 Blue／Pink，初始 Blue 先手。掷骰后按落点抽卡，依据当前角色结算。角色交换不交换位置或余额。恰好到达终点获胜；超出则退回。强制付款后余额为 0 或无法支付时，另一方获胜。完整操作说明可在游戏中点击“怎么玩”查看。

## 第一轮原型

已包含掷骰、抽卡、办公室情境、角色交换、自动结算、胜负判定、回合记录与本机存档。棋子暂用 A／B 标记；结束页面为简版。

以下为当前试玩约定，后续将根据反馈调整：

- 每种独立情境卡一张；同类别抽完后洗回弃牌。
- 牌面费用为强制结算，目前没有可选购买。
- 工资卡一张，Blue +$100／Pink +$80；办公室也可能抽到绩效或着装卡。
- 夹克和牛仔裤的 Pink $20 合计包含 $5 包费。
- 当前交通卡仅结算费用，不额外移动。

待复查：抽卡循环与各牌数量、购买选择、结束页面、正式棋子、英文切换，以及高额支出对游戏时长的影响。游戏情境与金额用于设计体验，不代表对所有人的现实经历或经济差异的精确测量。

## 本地运行与测试

需要支持 `node:test` 和 `structuredClone` 的 Node.js，无第三方运行依赖。

```sh
npm start
```

打开 http://127.0.0.1:4173 。

```sh
npm test
```

测试覆盖回合、角色交换、终点回退、破产、分类牌堆循环、重复操作与存档状态，并包含 200 局模拟对局。

## 修改与发布

- `game-data.js`：棋盘路线、卡牌金额与中文说明。
- `game-engine.js`：游戏规则。
- `app.js`、`index.html`、`style.css`：交互和页面布局。
- `assets/`：从原设计提取的图片。

GitHub Pages 从 `main` 分支根目录发布。后续提交到 `main` 会自动更新同一个游戏网址，无需重新分享链接。更新后刷新网页即可加载新版；若牌组或存档结构改变，应同步更新存档版本并说明是否需要重新开始。
